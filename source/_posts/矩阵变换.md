## 一、矩阵和向量乘法的几何意义

在上一篇博客 [线性代数的本质](https://littlefish04.github.io/blog/posts/1716614297/) 中我们讲到，矩阵可以用来表示变换。那么，矩阵究竟是如何表示变换的？这需要从向量坐标的本质说起。

### 1.1 基向量与坐标系

我们平时写下的向量坐标，实际上都以 **基向量**（basis vectors）为参照。在二维空间中，标准基向量是：

- **i-hat**（$\hat{i}$）：沿 x 轴方向的单位向量，即 `(1, 0)`
- **j-hat**（$\hat{j}$）：沿 y 轴方向的单位向量，即 `(0, 1)`

当我们写下向量 `(3, 2)` 时，它实际上是 $3 \cdot \hat{i} + 2 \cdot \hat{j}$ 的简写。也就是说，**向量的坐标就是各基向量的缩放系数**——每个分量告诉我们在对应基向量方向上"走多远"。

> 基向量定义了空间的"度量框架"。同一组坐标，放在不同的基向量下，会指向空间中完全不同的位置。我们日常使用的坐标，都是建立在标准基向量这一隐含约定之上的。

### 1.2 矩阵的列就是变换后的基向量

这是理解矩阵变换最关键的一步：**矩阵的每一列，就是对应基向量经过变换后落在的新位置。**

以二维矩阵为例：

```text
    ┌     ┐
M = │ a c │
    │ b d │
    └     ┘
```

- **第一列** `(a, b)` —— 是 i-hat `(1, 0)` 变换后的结果
- **第二列** `(c, d)` —— 是 j-hat `(0, 1)` 变换后的结果

也就是说，矩阵记录的是**基向量的"去向"**。一旦知道了 $\hat{i}$ 和 $\hat{j}$ 被变换到了哪里，空间中任意一点的变换结果也就随之确定了——因为任意向量都是基向量的线性组合。

> 可以把矩阵看作一份"变换说明书"：它不直接告诉你每个点会移到哪里，而是告诉你整个坐标系的骨架（基向量）是怎么变化的。骨架定了，空间中所有点的位置就自然确定了。

### 1.3 矩阵与向量的乘法

用矩阵乘以向量，本质上是用变换后的基向量重新组合出结果向量：

```text
┌     ┐ ┌   ┐     ┌   ┐     ┌   ┐   ┌          ┐
│ a c │ │ x │     │ a │     │ c │   │ ax + cy  │
│ b d │ │ y │ = x │ b │ + y │ d │ = │ bx + dy  │
└     ┘ └   ┘     └   ┘     └   ┘   └          ┘
```

结果向量的每个分量，都是用**原坐标作为权重**，对变换后的基向量做加权求和。这正是线性变换的核心特征：**变换后的向量 = 变换后的基向量按原坐标的线性组合**。

> 这也解释了为什么线性变换必须满足"网格线保持平行且等距"——因为变换后的基向量必须是空间中唯一确定的两个方向。如果基向量的去向不唯一（例如在曲面上），"按原坐标重新组合"这个操作就失去了意义，也就不是线性变换了。
