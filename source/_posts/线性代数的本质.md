## 一、向量究竟是什么？

**视频 P1**：在线性代数中，"向量"到底是什么？——这是整个系列的起点。

### 向量的三种视角

向量有三种常见的理解方式：

- **物理视角**：向量是空间中的箭头，具有**长度**和**方向**。它可以在空间中自由平移，只要长度和方向不变，它就是同一个向量。
- **计算机视角**：向量是**有序的数字列表**，例如 `[3, 5]`。每个数字代表一个维度上的分量。
- **数学视角**：向量是任何满足**加法**和**数乘**两种运算规则的对象。这是最抽象但最普适的定义。

> 本系列的核心哲学是：用**几何直觉**来理解线性代数，把向量看作从原点出发的箭头。

### 向量的两种基本运算

**向量加法**：在几何上，将两个向量的尾部相连（tip-to-tail），从第一个向量的起点走向第二个向量的终点。在坐标上，对应分量相加。

**标量乘法（数乘）**：将向量拉伸或压缩。乘以大于 1 的标量 → 拉伸；乘以 0 到 1 之间 → 压缩；乘以负数 → 翻转方向并缩放。

> 线性代数的一切都围绕着这两种运算展开。

## 二、线性组合、张成的空间与基

**视频 P2**：理解向量本质上是"基向量缩放后的和"，这是后续所有内容的基石。

### 基向量（Basis Vectors）

在二维平面中，有两个特殊的向量：

- `î`（i-hat）：指向 x 轴正方向，长度为 1。
- `ĵ`（j-hat）：指向 y 轴正方向，长度为 1。

任何向量 `[x, y]` 都可以表示为：
```
[x, y] = x·î + y·ĵ
```

换句话说，向量的**每个分量都是一个标量**，表示要将对应的基向量拉伸多少倍。

> 基向量的选择不是唯一的。我们完全可以用不同的基向量来构建另一套坐标系。

### 线性组合（Linear Combination）

两个向量 `v` 和 `w` 的**线性组合**是指：
```
a·v + b·w
```
其中 `a` 和 `b` 是任意实数标量。

### 张成空间（Span）

两个向量所有可能的线性组合构成的集合，叫做这两个向量的**张成空间**。

- 两个不共线的二维向量 → 张成整个二维平面
- 两个共线的二维向量 → 只张成一条直线
- 两个都是零向量 → 只张成原点（一个点）

> 张成空间可以是一个点、一条线、一个平面，或者是更高维的空间。

### 线性相关与线性无关

- **线性无关**：一组向量中，没有任何一个向量可以被其余向量的线性组合所表示。也就是说，每个向量都为张成空间**贡献了一个新的维度**。
- **线性相关**：至少有一个向量是冗余的——它落在其余向量张成的空间之内。移除它不会缩小张成空间。

## 三、矩阵与线性变换

**视频 P3**：这是整个系列最重要的洞察——矩阵不是一堆数字，而是对空间施加的某种**变换**。

### 线性变换的两个条件

一个变换是**线性**的，当且仅当它满足：

1. **直线在变换后仍然是直线**（不能弯曲）
2. **原点保持不变**（不能平移）

> 等价的说法是：变换后网格线保持**平行**且**等距分布**。

### 矩阵就是变换的"快照"

线性变换的关键性质：由于变换后网格线仍然平行且等距，你只需要知道 `î` 和 `ĵ` **变换后落在哪里**，就能推断出**任意向量变换后的位置**。

假设 `î` 变换到了 `[a, c]`，`ĵ` 变换到了 `[b, d]`，那么对于任意向量 `[x, y]`：
```
变换后 = x·[a, c] + y·[b, d]
```

这正好等同于矩阵乘法：
```
⎡ a  b ⎤ ⎡ x ⎤   ⎡ ax + by ⎤
⎣ c  d ⎦ ⎣ y ⎦ = ⎣ cx + dy ⎦
```

> **矩阵的每一列，就是对应基向量变换后的坐标。** 这就是矩阵的几何意义。

## 四、矩阵乘法与线性变换复合

**视频 P4**：当我们先后施加两个线性变换时，矩阵乘法描述的就是这个**复合变换**。

### 复合变换

假设先施加变换 `M1`（对应矩阵 A），再施加变换 `M2`（对应矩阵 B），总体效果等价于一个**单一的线性变换**。这个复合变换的矩阵记为 `BA`（注意顺序）。

> **矩阵乘法的几何意义**：`BA` 表示先做变换 A，再做变换 B。阅读时**从右向左**读。

### 矩阵乘法不满足交换律

```
AB ≠ BA（一般情况）
```

先旋转再剪切 ≠ 先剪切再旋转。几何上，操作的顺序不同，结果自然不同。

### 矩阵乘法满足结合律

```
(AB)C = A(BC)
```

几何解释：无论是先把 B 和 C 组合起来再与 A 组合，还是先与 A 和 B 组合再与 C 组合，最终的三个变换叠加效果是一样的。

## 五、三维空间中的线性变换

**视频 P5**：将前几章的二维直觉推广到三维。

### 三维基向量

在三维空间中，有三个基向量：
- `î`：x 轴方向
- `ĵ`：y 轴方向
- `k`（k-hat）：z 轴方向

### 三维线性变换

同样的原理：只要知道 `î`、`ĵ`、`k` 变换后的三维坐标，就能用一个 3×3 的矩阵描述三维空间中的任意线性变换。

矩阵的每一列依次是 `î`、`ĵ`、`k` 变换后的坐标。任意向量 `[x, y, z]` 变换后等于：
```
x·(î 变换后) + y·(ĵ 变换后) + z·(k 变换后)
```

### 三维变换中的线性相关

如果三个列向量线性相关（即一个列向量落在另外两个列向量张成的平面内），那么整个三维空间会被**压缩**到一个平面、一条线、甚至一个点上。

## 六、行列式

**视频 P6**：行列式衡量的是线性变换对**面积（或体积）的缩放比例**。

### 几何定义

在二维中，行列式的值 = 变换后 `î` 和 `ĵ` 所张成的**平行四边形的有向面积**。

- `det(A) > 0`：空间被拉伸，面积缩放，**方向保持不变**
- `det(A) < 0`：空间被**翻转**（镜像），面积缩放至 |det| 倍
- `det(A) = 0`：空间被**压缩**到更低维度（降维打击），面积变为 0

### 三维中的行列式

三维行列式衡量的是变换后 `î`、`ĵ`、`k` 所张成的**平行六面体的有向体积**。

正负号同样表示方向是否翻转。三维中的方向可以用**右手定则**来判断。

### 行列式的计算

对于 2×2 矩阵：
```
det⎡ a  b ⎤ = ad - bc
   ⎣ c  d ⎦
```

对于 3×3 矩阵，使用代数余子式展开（或行列式展开公式）。

> **行列式为 0 是降维的信号**——整个空间被压扁了。这也意味着变换不可逆。

## 七、逆矩阵、列空间、秩与零空间

**视频 P7**：线性方程组 `Ax = v` 的几何意义是——找到变换前的向量 `x`，使得它变换后恰好落在 `v` 上。

### 逆矩阵 = "撤销"变换

如果行列式不为 0（空间没有被压扁），那么变换 A 是**可逆**的。`A⁻¹` 就是"反向变换"，它把每个向量变回原来的位置：
```
A⁻¹(Ax) = x
```

求解 `Ax = v` 等价于 `x = A⁻¹v`。

**为什么空间被压扁了，变换就不可逆？**

逆变换的本质是"原路返回"——给定变换后的输出，找到唯一的输入。但当空间被压扁时，**无数个不同的输入向量会被压缩到同一个输出向量上**。信息在这个过程中丢失了。

以二维压缩到一条直线为例：变换后直线上的每一个点，都对应着变换前平面上的**一整条线上的所有点**。面对这样一个输出，你无法判断它究竟来自一整条"输入线"上的哪个位置——这就是为什么逆矩阵不存在。

> 打个比方：你把一张纸揉成一条线，拿到这条线后，你无法还原出原来那张二维的纸——因为太多不同的二维形状揉成线后看起来都一样。

数学上讲：要存在逆矩阵，变换必须是**一对一的映射**（双射）。而行列式为 0 意味着变换变成了**多对一**的映射——多个输入 → 同一个输出。无法"撤销"。

### 列空间（Column Space）

矩阵 A 的**列空间** = A 的所有列向量张成的空间 = 所有可能的输出 `Av` 的集合。

换句话说，列空间就是变换后空间所"覆盖"的区域。它告诉我们：`v` 在什么位置时，方程 `Ax = v` 才有解。

### 秩（Rank）

**秩** = 列空间的维数 = 变换后输出空间的维数。

- **满秩**：列空间的维数等于输入空间的维数。行列式 ≠ 0，变换可逆。
- **非满秩**：输出空间的维数小于输入空间的维数。行列式 = 0，变换将空间压缩到更低的维度。

> 秩描述了变换后的结果"占了几维"。

### 零空间 / 核（Null Space / Kernel）

变换后落在**原点**的所有向量的集合：
```
{x | Ax = 0}
```

- 满秩时，零空间只包含原点（零向量）。
- 非满秩时，零空间包含整条线、整个平面等——整条线/整个面上的向量全部被压缩到原点。

> **秩 + 零度 = 输入空间的维数**（Rank-Nullity 定理）

## 八、非方阵——不同维度空间之间的线性变换

**视频 P8**：将线性变换的概念扩展到不同维度的空间之间。

### 矩阵形状的含义

| 属性 | 含义 |
|------|------|
| **列数** | 输入空间的维数（多少个基向量进入） |
| **行数** | 输出空间的维数（每个结果有多少个坐标） |

### 三种情况

**2D → 3D（3×2 矩阵）**：将二维平面"抬升"嵌入到三维空间中。两个列向量定义了二维平面在三维空间中的位置和方向。列空间是三维空间中的一个二维平面。

**3D → 2D（2×3 矩阵）**：将三维空间"压扁"到二维平面上。三个列向量将三维空间中的所有点都映射到二维。这便是计算机图形学中将 3D 场景投影到 2D 屏幕的数学原理。

**2D → 1D（1×2 矩阵）**：将整个二维平面映射到一条数轴上。这与下一章**点积**有着深刻的联系。

> 非方阵没有行列式（因为改变了维度，"面积缩放"不再有意义），也没有普通的逆矩阵（因为压缩维度的过程不可逆转）。

## 九、点积与对偶性

**视频 P9**：点积不仅是代数运算，它背后隐藏着**投影变换**和**对偶性**的深刻洞察。

### 点积的两种定义

**数值定义**：对应分量相乘再相加
```
v · w = v₁w₁ + v₂w₂ + ... + vₙwₙ
```

**几何定义**：`v` 在 `w` 方向上的投影长度 × `w` 的长度
```
v · w = |v| × |w| × cos(θ)
```

- 点积 > 0：两个向量大致**同向**
- 点积 = 0：两个向量**垂直**（正交）
- 点积 < 0：两个向量大致**反向**

### 点积与线性变换的联系

考虑一个从 2D 映射到 1D 的线性变换，它由一个 1×2 矩阵 `[u_x, u_y]` 描述：
```
[u_x, u_y] · [v_x, v_y]ᵀ = u_x·v_x + u_y·v_y
```

这恰好等同于向量 `u = [u_x, u_y]` 与 `v` 的**点积**！

> **每一个从多维到一维的线性变换，都对应着与某个向量的点积。** 反之亦然——每一个向量都定义了一个"与自己做点积"的线性变换。

### 对偶性（Duality）

**对偶性**指的是两种看似不同的数学对象之间存在的自然一一对应关系。

在这里：
- 向量 ⇔ 从高维到一维的线性变换（即**线性泛函**）
- 点积就是这种对应关系的桥梁

> 将向量 `v` 投影到 `u` 所在直线上的变换矩阵，恰好就是 `[u_x, u_y]`。其中 `u_x` 和 `u_y` 正是 `î` 和 `ĵ` 投影到该直线上的坐标。

## 十、叉积的标准介绍

**视频 P10**：两个三维向量可以生成一个垂直于它们的新向量——这就是叉积。

### 叉积的定义

对于两个三维向量 `v` 和 `w`，它们的叉积 `v × w` 是一个同时**垂直于** `v` 和 `w` 的向量，其：

- **方向**：由**右手定则**确定——右手四指从 `v` 弯向 `w`，拇指所指方向即为叉积方向。
- **长度**：等于 `v` 和 `w` 所张成**平行四边形的面积**：`|v| × |w| × sin(θ)`

### 叉积的计算公式

常用的记忆方式是写成行列式的形式：
```
v × w = det⎡ î  ĵ  k  ⎤
           ⎢ v₁ v₂ v₃ ⎥
           ⎣ w₁ w₂ w₃ ⎦
```

展开后得到每个分量上的表达式。

> 行列式公式看起来像是巧合——但下一章将揭示这背后的深层原因。

### 叉积的性质

- **反交换律**：`v × w = -(w × v)`（交换后方向反转）
- 叉积结果垂直于参与运算的两个向量
- 两个平行向量的叉积为零向量

## 十一、以线性变换的眼光看叉积

**视频 P11**：这是系列中最精彩的章节之一，它揭示了叉积公式根本不是巧合。

### 第一步：构造一个从三维到一维的线性函数

给定两个向量 `v` 和 `w`，定义一个函数 `f`，它接收任意第三个向量 `[x, y, z]`，输出由 `v`、`w` 和 `[x, y, z]` 确定的**平行六面体的有向体积**：
```
f([x, y, z]) = det([v  w  [x, y, z]])
```

这个函数是**线性**的（行列式对每一列都是线性的）。

### 第二步：利用对偶性

根据对偶性（第九章），每一个从三维到一维的线性函数都等价于**与某个向量的点积**。也就是说，存在一个唯一的向量 `p`，使得：
```
f([x, y, z]) = p · [x, y, z]
```

### 第三步：这个对偶向量就是叉积

这个 `p` 具有以下性质：
- 当 `[x, y, z]` 在 `v` 和 `w` 张成的平面内时，体积为 0，即 `p` 与平面内的所有向量垂直 → **`p` 垂直于 `v-w` 平面**
- 体积 = 底面积 × 高 → `p` 的长度刚好等于 `v` 和 `w` 张成的**平行四边形面积**

这正是叉积的几何定义！所以 `p = v × w`。

### 第四步：计算叉积的分量

将 `î`、`ĵ`、`k` 分别代入 `f`，就得到了 `p` 的三个分量——它们正是 2×2 的行列式（代数余子式），完美解释了行列式公式的来历。

> **叉积本质上是一个有向体积测度函数的对偶向量。**

## 十二、克莱姆法则的几何解释

**视频 P12**：从几何角度重新理解克莱姆法则——用面积（或体积）的比值来求解未知数。

### 核心思想

将一个向量的坐标理解为**有向面积/体积**。

在二维中：
- `y` 坐标 = `î` 与输入向量所张成平行四边形的**有向面积**（底 = 1，高 = y → 面积 = y）
- `x` 坐标 = 输入向量与 `ĵ` 所张成平行四边形的**有向面积**

### 利用行列式的缩放性质

施加变换 A 后，**所有区域的面积都按 `det(A)` 的比例缩放**。

`det(A) × y` = 变换后的平行四边形（由 A 的第一列和输出向量 `b` 张成）的面积。

因此：
```
y = det([col₁(A), b]) / det(A)
x = det([b, col₂(A)]) / det(A)
```

### 克莱姆法则的一般形式

对于 `Ax = b`（A 可逆），第 `i` 个未知数：
```
xᵢ = det(Aᵢ(b)) / det(A)
```

其中 `Aᵢ(b)` 是将 A 的第 `i` 列**替换为 `b`** 后得到的矩阵。

> 克莱姆法则在实际计算中不如高斯消元高效，但它揭示了行列式与线性方程组之间的几何联系。

## 十三、基变换

**视频 P13**：空间本身没有网格——坐标系只是我们人为选择的。基变换就是切换观察同一个向量的"坐标系"。

### 核心思想

同一个空间中的向量，在不同的基（坐标系）下有不同的坐标表示。

### 三种情景

**情景一：基变但向量不变**——空间中的箭头不变，但换了基来重新描述。坐标发生了变化。
- 从"新基"翻译到"标准基"：乘以**基变换矩阵**，得到的就是新基的基向量在标准基下的坐标。
- 从"标准基"翻译到"新基"：乘以基变换矩阵的**逆矩阵**。

**情景二：在另一组基下描述线性变换**——同一个变换在不同的基下有不同的矩阵表示。
```
A_new = S⁻¹ · A · S
```
其中 S 是基变换矩阵（新基向量作为列）。这个公式的含义是：
1. 将新基下的坐标翻译到标准基（乘 S）
2. 在标准基下施加变换（乘 A）
3. 将结果翻译回新基（乘 S⁻¹）

`A_new` 和 `A` 被称为**相似矩阵**。

### 基变换的威力

选择**好的基**可以极大地简化变换的矩阵表示。这是下一章"特征向量与特征值"的动机——特征基是对角矩阵的"最佳基"。

---

## 十四、特征向量与特征值

**视频 P14**：揭示线性变换的"内在结构"——哪些向量在变换中方向不变。

### 几何定义

在线性变换中，大多数向量会被**甩离**自己原来所在的直线。但有一些特殊的向量，变换后仍然**留在自己张成的直线上**——只是被拉伸、压缩或翻转。这些向量就是**特征向量**。对应的缩放因子就是**特征值**。

```
Av = λv
```

- `A`：变换矩阵
- `v`：特征向量（非零）
- `λ`：特征值

| λ 的值 | 效果 |
|--------|------|
| λ > 1 | 拉伸 |
| 0 < λ < 1 | 压缩 |
| λ = 1 | 保持不变 |
| λ < 0 | 翻转后再缩放 |
| λ = 0 | 压缩到原点 |

例如：对于 `[[3,1],[0,2]]` 变换矩阵，`[-1,1] `为特征值为２的特征向量，`[1,0]` 为特征值为3的特征向量。

![](特征向量演示.webp)

### 各类变换的特征向量/特征值

| 变换 | 特征向量 | 特征值 |
|------|----------|--------|
| 各向缩放 2 倍 | **所有向量** | 2 |
| 90° 旋转 | 无实数特征向量 | 虚数 ±i |
| 剪切 `[[1,1],[0,1]]` | 仅 x 轴向量 | 1 |
| 对角矩阵 | 坐标轴方向 | 对角线元素 |

### 求解特征值

方程 `(A - λI)v = 0` 要有非零解，`(A - λI)` 必须将空间压缩（行列式为 0）：
```
det(A - λI) = 0
```

这是一个关于 `λ` 的多项式方程（**特征多项式**），解出 `λ` 后再代入原方程求 `v`。

### 特征基与对角化

如果变换有**足够多的特征向量**能够张成整个空间（即存在一个**特征基**），那么在这个特征基下，变换矩阵就是**对角矩阵**，对角线上的元素就是特征值。这意味着：
```
Aⁿ = S · Dⁿ · S⁻¹
```
计算高次幂变得极其简单——因为对角矩阵的 n 次幂只需将对角线元素各自乘 n 次方。

> 并非所有矩阵都能对角化。剪切矩阵只有一个特征方向，不足以张成整个二维平面，因此不能对角化。

## 系列总结

线性代数本质上是关于**空间变换**的语言。矩阵是变换的编码，行列式衡量缩放，特征向量揭示不变方向，而对偶性贯穿始终。最重要的是：这套思维工具远超箭头和几何——它是描述任何满足"线性"规则的系统的通用框架。
