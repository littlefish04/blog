    一、向量究竟是什么？

    视频 P1：在线性代数中，”向量”到底是什么？——这是整个系列的起点。

    向量的三种视角

    向量有三种常见的理解方式：

    • 物理视角：向量是空间中的箭头，具有长度和方向。它可以在空间中自由平移，只要长度和方向不变，它就是同一个向量。
    • 计算机视角：向量是有序的数字列表，例如 [3, 5]。每个数字代表一个维度上的分量。
    • 数学视角：向量是任何满足加法和数乘两种运算规则的对象。这是最抽象但最普适的定义。

    本系列的核心哲学是：用几何直觉来理解线性代数，把向量看作从原点出发的箭头。

    向量的两种基本运算

    向量加法：在几何上，将两个向量的尾部相连（tip-to-tail），从第一个向量的起点走向第二个向量的终点。在坐标上，对应分量相加。

    标量乘法（数乘）：将向量拉伸或压缩。乘以大于 1 的标量 → 拉伸；乘以 0 到 1 之间 → 压缩；乘以负数 → 翻转方向并缩放。

    线性代数的一切都围绕着这两种运算展开。

    二、线性组合、张成的空间与基

    • î（i-hat）：指向 x 轴正方向，长度为 1。
    • ĵ（j-hat）：指向 y 轴正方向，长度为 1。

    张成空间（Span）

    两个向量所有可能的线性组合构成的集合，叫做这两个向量的张成空间。

    • 两个不共线的二维向量 → 张成整个二维平面
    • 两个共线的二维向量 → 只张成一条直线
    • 两个都是零向量 → 只张成原点（一个点）

    张成空间可以是一个点、一条线、一个平面，或者是更高维的空间。

    线性相关与线性无关

    • 线性无关：一组向量中，没有任何一个向量可以被其余向量的线性组合所表示。也就是说，每个向量都为张成空间贡献了一个新的维度。
    • 线性相关：至少有一个向量是冗余的——它落在其余向量张成的空间之内。移除它不会缩小张成空间。

    三、矩阵与线性变换

    视频 P3：这是整个系列最重要的洞察——矩阵不是一堆数字，而是对空间施加的某种变换。

    线性变换的两个条件

    一个变换是线性的，当且仅当它满足：

    1. 直线在变换后仍然是直线（不能弯曲）
    2. 原点保持不变（不能平移）

    等价的说法是：变换后网格线保持平行且等距分布。

    矩阵就是变换的”快照”

    四、矩阵乘法与线性变换复合

    视频 P4：当我们先后施加两个线性变换时，矩阵乘法描述的就是这个复合变换。

    复合变换

    假设先施加变换 M1（对应矩阵 A），再施加变换 M2（对应矩阵 B），总体效果等价于一个单一的线性变换。这个复合变换的矩阵记为 BA（注意顺序）。

    矩阵乘法的几何意义：BA 表示先做变换 A，再做变换 B。阅读时从右向左读。

    矩阵乘法不满足交换律

    先旋转再剪切 ≠ 先剪切再旋转。几何上，操作的顺序不同，结果自然不同。

    矩阵乘法满足结合律

    几何解释：无论是先把 B 和 C 组合起来再与 A 组合，还是先与 A 和 B 组合再与 C 组合，最终的三个变换叠加效果是一样的。

    六、行列式

    视频 P6：行列式衡量的是线性变换对面积（或体积）的缩放比例。

    几何定义

    在二维中，行列式的值 = 变换后 î 和 ĵ 所张成的平行四边形的有向面积。

    • det(A) > 0：空间被拉伸，面积缩放，方向保持不变

    • det(A) = 0：空间被压缩到更低维度（降维打击），面积变为 0

    七、逆矩阵、列空间、秩与零空间

    视频 P7：线性方程组 Ax = v 的几何意义是——找到变换前的向量 x，使得它变换后恰好落在 v 上。

    逆矩阵 = “撤销”变换

    如果行列式不为 0（空间没有被压扁），那么变换 A 是可逆的。A⁻¹ 就是”反向变换”，它把每个向量变回原来的位置：

    求解 Ax = v 等价于 x = A⁻¹v。

    为什么空间被压扁了，变换就不可逆？

    逆变换的本质是”原路返回”——给定变换后的输出，找到唯一的输入。但当空间被压扁时，无数个不同的输入向量会被压缩到同一个输出向量上。信息在这个过程中丢失了。

    以二维压缩到一条直线为例：变换后直线上的每一个点，都对应着变换前平面上的一整条线上的所有点。面对这样一个输出，你无法判断它究竟来自一整条”输入线”上的哪个位置——这就是为什么逆矩阵不存在。

    打个比方：你把一张纸揉成一条线，拿到这条线后，你无法还原出原来那张二维的纸——因为太多不同的二维形状揉成线后看起来都一样。

    数学上讲：要存在逆矩阵，变换必须是一对一的映射（双射）。而行列式为 0 意味着变换变成了多对一的映射——多个输入 → 同一个输出。无法”撤销”。

    列空间（Column Space）

    矩阵 A 的列空间 = A 的所有列向量张成的空间 = 所有可能的输出 Av 的集合。

    换句话说，列空间就是变换后空间所”覆盖”的区域。它告诉我们：v 在什么位置时，方程 Ax = v 才有解。

    秩（Rank）

    秩 = 列空间的维数 = 变换后输出空间的维数。

    • 满秩：列空间的维数等于输入空间的维数。行列式 ≠ 0，变换可逆。
    • 非满秩：输出空间的维数小于输入空间的维数。行列式 = 0，变换将空间压缩到更低的维度。

    秩描述了变换后的结果”占了几维”。

    零空间 / 核（Null Space / Kernel）

    变换后落在原点的所有向量的集合：

    • 满秩时，零空间只包含原点（零向量）。
    • 非满秩时，零空间包含整条线、整个平面等——整条线/整个面上的向量全部被压缩到原点。

    秩 + 零度 = 输入空间的维数（Rank-Nullity 定理）

    八、非方阵——不同维度空间之间的线性变换

    视频 P8：将线性变换的概念扩展到不同维度的空间之间。

    矩阵形状的含义

    属性 含义
    列数 输入空间的维数（多少个基向量进入）
    行数 输出空间的维数（每个结果有多少个坐标）

    三种情况

    2D → 3D（3×2 矩阵）：将二维平面”抬升”嵌入到三维空间中。两个列向量定义了二维平面在三维空间中的位置和方向。列空间是三维空间中的一个二维平面。

    3D → 2D（2×3 矩阵）：将三维空间”压扁”到二维平面上。三个列向量将三维空间中的所有点都映射到二维。这便是计算机图形学中将 3D 场景投影到 2D 屏幕的数学原理。

    2D → 1D（1×2 矩阵）：将整个二维平面映射到一条数轴上。这与下一章点积有着深刻的联系。

    非方阵没有行列式（因为改变了维度，”面积缩放”不再有意义），也没有普通的逆矩阵（因为压缩维度的过程不可逆转）。

    九、点积与对偶性

    视频 P9：点积不仅是代数运算，它背后隐藏着投影变换和对偶性的深刻洞察。

    点积的两种定义

    数值定义：对应分量相乘再相加

    几何定义：v 在 w 方向上的投影长度 × w 的长度

    • 点积 > 0：两个向量大致同向
    • 点积 = 0：两个向量垂直（正交）
    • 点积 < 0：两个向量大致反向

    点积与线性变换的联系

    考虑一个从 2D 映射到 1D 的线性变换，它由一个 1×2 矩阵 [u_x, u_y] 描述：

    这恰好等同于向量 u = [u_x, u_y] 与 v 的点积！

    每一个从多维到一维的线性变换，都对应着与某个向量的点积。 反之亦然——每一个向量都定义了一个”与自己做点积”的线性变换。

    对偶性（Duality）

    对偶性指的是两种看似不同的数学对象之间存在的自然一一对应关系。

    在这里：

    • 向量 ⇔ 从高维到一维的线性变换（即线性泛函）
    • 点积就是这种对应关系的桥梁

    将向量 v 投影到 u 所在直线上的变换矩阵，恰好就是 [u_x, u_y]。其中 u_x 和 u_y 正是 î 和 ĵ 投影到该直线上的坐标。

    十、叉积的标准介绍

    视频 P10：两个三维向量可以生成一个垂直于它们的新向量——这就是叉积。

    叉积的定义

    对于两个三维向量 v 和 w，它们的叉积 v × w 是一个同时垂直于 v 和 w 的向量，其：

    • 方向：由右手定则确定——右手四指从 v 弯向 w，拇指所指方向即为叉积方向。
    • 长度：等于 v 和 w 所张成平行四边形的面积：|v| × |w| × sin(θ)

    叉积的性质

    • 反交换律：v × w = -(w × v)（交换后方向反转）
    • 叉积结果垂直于参与运算的两个向量
    • 两个平行向量的叉积为零向量

    叉积本质上是一个有向体积测度函数的对偶向量。

    十二、克莱姆法则的几何解释

    十三、基变换

    视频 P13：空间本身没有网格——坐标系只是我们人为选择的。基变换就是切换观察同一个向量的”坐标系”。

    核心思想

    同一个空间中的向量，在不同的基（坐标系）下有不同的坐标表示。

    三种情景

    情景一：基变但向量不变——空间中的箭头不变，但换了基来重新描述。坐标发生了变化。

    • 从”新基”翻译到”标准基”：乘以基变换矩阵，得到的就是新基的基向量在标准基下的坐标。
    • 从”标准基”翻译到”新基”：乘以基变换矩阵的逆矩阵。

    情景二：在另一组基下描述线性变换——同一个变换在不同的基下有不同的矩阵表示。

    其中 S 是基变换矩阵（新基向量作为列）。这个公式的含义是：

    1. 将新基下的坐标翻译到标准基（乘 S）
    2. 在标准基下施加变换（乘 A）
    3. 将结果翻译回新基（乘 S⁻¹）

    A_new 和 A 被称为相似矩阵。

    基变换的威力

    选择好的基可以极大地简化变换的矩阵表示。这是下一章”特征向量与特征值”的动机——特征基是对角矩阵的”最佳基”。

    十四、特征向量与特征值

    视频 P14：揭示线性变换的”内在结构”——哪些向量在变换中方向不变。

    几何定义

    在线性变换中，大多数向量会被甩离自己原来所在的直线。但有一些特殊的向量，变换后仍然留在自己张成的直线上——只是被拉伸、压缩或翻转。这些向量就是特征向量。对应的缩放因子就是特征值。

    • A：变换矩阵
    • v：特征向量（非零）
    • λ：特征值
    λ 的值 效果
    λ > 1 拉伸
    0 < λ < 1 压缩
    λ = 1 保持不变
    λ < 0 翻转后再缩放
    λ = 0 压缩到原点

    例如：对于 [[3,1],[0,2]] 变换矩阵，[-1,1] 为特征值为２的特征向量，[1,0] 为特征值为3的特征向量。

    各类变换的特征向量/特征值

    变换 特征向量 特征值

    90° 旋转 无实数特征向量 虚数 ±i
    剪切 [[1,1],[0,1]] 仅 x 轴向量 1
    对角矩阵 坐标轴方向 对角线元素

    线性代数本质上是关于空间变换的语言。矩阵是变换的编码，行列式衡量缩放，特征向量揭示不变方向，而对偶性贯穿始终。最重要的是：这套思维工具远超箭头和几何——它是描述任何满足”线性”规则的系统的通用框架。
